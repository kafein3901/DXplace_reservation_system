# 設計で定めた値

要件で「設計で定める」とされた値と、設計で決めた数値の一覧。理由は「決めた文書」にある。値を変えるときは、決めた文書とこの表の両方を直す。

| 値 | 内容 | 要件 | 決めた文書 | 状態 |
| --- | --- | --- | --- | --- |
| 管理者の ID の形式 | 3〜32文字。半角の英小文字・数字・ハイフン・アンダースコアで、先頭は英字。全角は半角に、英字は小文字にそろえて比べる | ADM-2 | [auth.md](auth.md) 5 | 決定 |
| 共有された情報の条件 | 台帳が作るランダムな32バイト（base64url 43文字）。QR コードで渡し、人は値を決めない | SEC-3 | [auth.md](auth.md) 2, 5 | 確認済み（QR コードは開発者が決定） |
| 管理者のパスワードの条件 | 15〜128文字。空白を除く表示できる ASCII。そろえない | SEC-3 | [auth.md](auth.md) 5 | 決定 |
| 試行の制限：共有された情報 | 同じ相手（IP。IPv6 は /64）からの失敗が、10分ごとに20回まで | SEC-3 | [auth.md](auth.md) 7 | 決定 |
| 試行の制限：管理者の認証 | 同上、10分ごとに10回まで | SEC-3 | [auth.md](auth.md) 7 | 決定 |
| 試行の制限：保守用の API | 同上、10分ごとに5回まで | SEC-3 | [auth.md](auth.md) 7 | 決定 |
| 管理者の認証の期限 | なし（認証を解く操作と ADM-2 の操作でだけ止まる） | ADM-2 | [auth.md](auth.md) 3 | 確認済み |
| PBKDF2 の反復回数（管理者のパスワード） | 仮に 10,000 回 | SEC-4 | [auth.md](auth.md) 4 | 実測待ち（[platform-selection.md](platform-selection.md) 未決事項2） |
| 機器の名前の上限 | 未定 | MNG-1 | ― | 未定 |
| 失敗の記録の持ち方 | 未定 | LOG-4 | ― | 未定（logging.md） |
| 利用がなかった時間の長さ | 未定 | OPN-1 | ― | 未定（実測待ち） |
