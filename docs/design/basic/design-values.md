# 設計で定めた値

要件で「設計で定める」とされた値と、設計で決めた数値の一覧。理由は「決めた文書」にある。値を変えるときは、決めた文書とこの表の両方を直す。

| 値 | 内容 | 要件 | 決めた文書 | 状態 |
| --- | --- | --- | --- | --- |
| 管理者の ID の形式 | 3〜32文字。半角の英小文字・数字・ハイフン・アンダースコアで、先頭は英字。全角は半角に、英字は小文字にそろえて比べる | ADM-2 | [auth.md](auth.md) 5 | 決定 |
| 共有された情報の条件 | 台帳が作るランダムな32バイト（base64url 43文字）。QR コードで渡し、人は値を決めない | SEC-3 | [auth.md](auth.md) 2, 5 | 確認済み（QR コードは開発者が決定） |
| 管理者のパスワードの条件 | 15〜128文字。空白を除く表示できる ASCII。そろえない | SEC-3 | [auth.md](auth.md) 5 | 決定 |
| 試行の制限：共有された情報 | 同じ相手（IP。IPv6 は /64）からの失敗が、10分ごとに200回まで。10分は、時刻を10分で切り捨てた固定の区切り | SEC-3 | [auth.md](auth.md) 7 | 決定（2026-11-17 に20回から変更） |
| 試行の制限：管理者の認証 | 同上、10分ごとに10回まで | SEC-3 | [auth.md](auth.md) 7 | 決定 |
| 試行の制限：保守用の API | 同上、10分ごとに5回まで | SEC-3 | [auth.md](auth.md) 7 | 決定 |
| 管理者の認証の期限 | なし（認証を解く操作と ADM-2 の操作でだけ止まる） | ADM-2 | [auth.md](auth.md) 3 | 確認済み |
| Cookie の期限 | 400日。使うたびに延ばして渡し直す（利用を始めた証明、管理者の認証とも） | USR-2, ADM-2 | [auth.md](auth.md) 3 | 決定 |
| PBKDF2 の反復回数（管理者のパスワード） | 100,000 回（workerd の上限） | SEC-4 | [auth.md](auth.md) 4、[platform-selection.md](platform-selection.md) 実測の結果 2 | 決定（2026-11-18） |

| API の本文の上限 | 16 KiB。超えたら読まずに `INPUT_BODY` | RSV-27 | [../detailed/api.md](../detailed/api.md) 2 | 決定（2026-11-19） |
| 失敗の記録の持ち方 | 入口・相手・10分の区切りごとに1行にまとめる。上限に達した後の試行は書かない。全体で10,000行を超えたら古いものから消す | LOG-4 | [logging.md](logging.md) 4 | 決定 |
| 利用がなかった時間の長さ | 24時間 | OPN-1 | [platform-selection.md](platform-selection.md) 実測の結果 4 | 決定（2026-11-18） |
